# Pre-Launch Audit (`PRE_LAUNCH_AUDIT.md`) — `insta-store`

- **Audit Scope:** Security, Performance, Accessibility, SEO, and Launch Operations across the full Storefront (`/`..`/checkout`), Owner Dashboard (`/admin/*`), D1 data layer, and API routes (`/api/*`), following the Phase 4 Goldfish Launch Audit (`egm-codebase-details`) and full post-audit remediation pass.
- **Verification Basis:** Static checks (`biome check`, `guard:filesize`, `guard:secrets`, `astro check`, `astro build`), Vitest suite (`18` tests), and live HTTP/D1 E2E verification against compiled Wrangler/Astro SSR output.

## 2. Production Launch Checklist (`Before Client Handoff`)

1. Set a unique `SESSION_SECRET` (`>= 24` random characters) via `wrangler secret put SESSION_SECRET`.
2. Provision production D1 (`wrangler d1 create`), apply `migrations/0001_init.sql`, and run `npm run seed:blank`.
3. Configure Turnstile (`TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`) and Cloudinary signed-upload secrets (`CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`) via `DEPLOY_GUIDE.md` / `scripts/deploy-client.sh`.
4. Log in to `/admin` on the live `workers.dev` or custom domain and change the initial seeded password immediately.
