# Project Domain Glossary (`GLOSSARY.md`)

> Use these exact terms consistently in `PRD.md`, `STACK.md`, file names, database schemas, UI copy, and tests.

| Term               | Exact Definition in This Project                                                                                                                                                                                                                       | Code / DB Identifier   | Do NOT Confuse With  |
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------- | :------------------- |
| **Storefront**     | The public-facing clothing store website visited by shoppers from Instagram bio/ads.                                                                                                                                                                   | `storefront`           | Admin Dashboard      |
| **Dashboard**      | The mobile-first private control panel used by the store owner to customize branding, manage products, shipping, coupons, and process orders.                                                                                                          | `dashboard` (`/admin`) | Storefront           |
| **Store Config**   | Single-row settings defining the store's white-label identity: name, logo, preset + accent `theme_tokens`, hero media + poster, `default_size_guide`, WhatsApp number, pixels, `global_free_shipping_threshold`, language mode, and currency.          | `store_config`         | Individual Product   |
| **Theme Tokens**   | CSS custom properties generated server-side from `store_config` (selected Impulse-inspired preset + custom brand accent/button/radius) injected inline in `<head>` to prevent FOUC.                                                                    | `theme_tokens`         | Hardcoded hex colors |
| **Collection**     | A clothing category/group (`id`, `name`, immutable `slug`, cover image, sort order, visibility).                                                                                                                                                       | `collection`           | Product              |
| **Product**        | A clothing item listed for sale (`title`, `description`, `base_price`, optional `compare_at_price`, `collection_id`, optional `size_guide`, `slug`, `status`: `published`/`hidden`, `deleted_at` for Trash).                                           | `product`              | Variant              |
| **Variant**        | A concrete purchasable combination of a `product` (`size`, `color_name`, `color_hex`, `stock`, optional `price_override`).                                                                                                                             | `variant`              | Product              |
| **Media Asset**    | A tracked uploaded file (`id`, `cloudinary_public_id`, `secure_url`, `resource_type`, `bytes`, owner reference) so replacements and Trash purges delete orphaned assets cleanly.                                                                       | `media_asset`          | Raw external URL     |
| **Permanent Slug** | Immutable URL path segment for a `product` (`/p/[slug]`) or `collection` (`/c/[slug]`) that remains valid even if the display title changes.                                                                                                           | `slug`                 | Display title        |
| **Shipping Zone**  | A governorate/region delivery fee rule (`name`, `fee`, optional per-zone `free_shipping_threshold` that overrides `store_config.global_free_shipping_threshold` when set).                                                                             | `shipping_zone`        | Promo Coupon         |
| **Promo Coupon**   | A discount code (`code`, `type`: `percentage` \| `fixed`, `value`, optional `min_subtotal`, `max_uses`, `used_count`, `expires_at`, `is_active`).                                                                                                      | `coupon`               | Shipping Zone        |
| **Guest Order**    | An order placed without customer login (COD) containing contact info, normalized Egyptian/local phone, `shipping_zone`, line-item price snapshots, `coupon` discount, `stock_state` (`reserved` \| `released`), `idempotency_key`, and `order_status`. | `order`                | Cart                 |
| **Order Status**   | Lifecycle state of a `Guest Order`: `new` → `confirmed` → `shipped` → `delivered` \| `cancelled`.                                                                                                                                                      | `order_status`         | `stock_state`        |
| **Admin Session**  | Server-side authenticated session validated via `HttpOnly; Secure; SameSite=Lax` signed cookie + `session_version` revocation check.                                                                                                                   | `admin_session`        | Storefront cookie    |
